Super Admin Style Guide

This extends the mobile field-app design language (forest green, mint accent, Inter) into the desktop admin surface — the console super admins use to manage methodologies, users, projects, and platform configuration. Same brand tokens, denser layout, more data per screen.

Color

Carried directly from the mobile app palette so the two products feel like one system. Desktop adds two neutrals (canvas vs. surface) since admin screens stack more panels than the phone ever does.

Radius & elevation

Sharp corners, deliberately: every button, card, input, badge, and panel on the admin dashboard is squared off. This is the one point of departure from the mobile app's rounded language — chosen for the admin surface to read as denser, more technical, more "control panel" than the field app.

Circles are the only exception: toggle switches, status dots, and step-number badges stay round because they're functional indicators, not boxes.

Buttons

Primary is reserved for the one committing action per screen (Publish methodology, Save changes). Never more than one primary button visible at once.

Form elements

Same input shape as mobile (10px radius, 1.5px border, forest-green focus ring) so the visual language never breaks across surfaces.

Methodology manager — composition guide

How the components above assemble into the actual admin flow.

List view — Table component, filterable by registry/status, "+ Add methodology" primary button top-right.
Detail view — Methodology card header (name, version, status badge, equation chips) + tabbed sections for Parameters, Equations, Mobile survey mapping, Version history.
Create/edit flow — Wizard component (Basics → Equations & parameters → Mobile survey mapping → Review & publish). Save as draft available at every step; Publish only enabled once required fields validate.
Publish confirmation — Modal (shadow-lg, radius-lg) restating what changes and which mobile app versions/projects are affected before the irreversible action.
Deprecation — Danger button, blocked with an alert-danger if active projects still reference the methodology (see Alerts above).
